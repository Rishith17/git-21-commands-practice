# Tiny Web App — Git Practice Repository

This is a deliberately small project for practicing everyday Git commands safely.

## Project files
- `index.html` — a tiny web page
- `app.py` — a simple Python example (no packages needed)
- `deploy.sh` — a sample shell script to inspect
- `CHANGELOG.md` — a file to edit during practice
- `.gitignore` — examples of files Git should ignore

## Start here
Read `PRACTICE_GUIDE.md` and follow the exercises in order.

**Safety rule:** practice in this folder only. Before using `git restore`, check `git status` and `git diff`, because `git restore` discards uncommitted changes.
